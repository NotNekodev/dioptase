# dioptase
little java virtual machine targeting java 1.8 written in rust :D

this was written in rust because i want to learn rust.

## examples
currently the only example provided is `examples/ReturnTest.java`, you can compile it with `javac examples/ReturnTest.java` (`javac` has to be version 1.8) and you can run the JVM on it with `cargo run -- examples/ReturnTest.class`
